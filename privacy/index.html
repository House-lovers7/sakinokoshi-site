プライバシーポリシー

最終更新日: 2026年3月26日

1. はじめに

本ポリシーは、Taisuke Goto（以下「開発者」）が提供する全てのアプリケーション（以下「本アプリ」）における情報の取り扱いについて説明します。本アプリはユーザーのプライバシーを最優先に設計されています。

2. 共通方針

開発者が提供する全てのアプリに共通する方針です：

  • ユーザーデータは端末内にのみ保存され、外部サーバーに送信しません
  • アカウント登録は不要です
  • 広告SDK、行動追跡、外部アナリティクスツールは利用していません
  • ユーザー情報を第三者へ販売、共有、提供することはありません

3. アプリ別の情報

🌱 先のこし

端末内に保存されるデータ:

  • 入力した金額、カテゴリ、履歴、設定情報

外部通信: なし（主要機能は完全オフライン）

🏠 家計の味方

端末内に保存されるデータ:

  • 設定情報（選択カテゴリ、地域、チェーン、世帯人数、通知設定）
  • 購入履歴（商品名、価格、数量、日時）
  • 通知購読情報

外部通信:

  • Sentry - エラー監視（匿名化されたエラー情報のみ）
  • e-Stat API - 消費者物価指数データの取得（個人情報は送信しません）

4. データの削除

各アプリの設定画面から、保存されている全てのデータを削除できます。アプリを削除すると、端末内の全データも自動的に削除されます。

5. Cookie・トラッキング

開発者のアプリはCookieやトラッキング技術を使用しません。

6. 児童のプライバシー

開発者のアプリは13歳未満の児童を対象としていません。

7. お問い合わせ時の情報

サポートへのお問い合わせ時に、ユーザーが任意で提供した情報（メールアドレス、問い合わせ内容など）は、お問い合わせ対応のためにのみ利用します。

8. ポリシーの変更

本ポリシーは、必要に応じて改定されることがあります。重要な変更がある場合は、最新の内容を本ページに掲載します。
